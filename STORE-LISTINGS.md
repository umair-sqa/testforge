# TestForge Gumroad listing copy

## Product title

TestForge Professional — TypeScript Playwright UI & API Automation Framework

## Short description

A documented TypeScript + Playwright starter framework with reusable authentication, UI and REST API examples, a local demo shop, cross-browser projects, CI configuration and failure diagnostics.

## Long description

Stop starting every automation project from an empty folder. TestForge gives QA engineers and SDETs a structured TypeScript + Playwright foundation that they can understand, run locally and adapt to their own web application.

### What is included

- Strict TypeScript project configuration
- Page Object Model and custom fixtures
- Reusable authentication setup and storage-state example
- UI examples for login, authenticated navigation, product catalogue, cart and checkout
- REST API examples for health, users, product catalogue and order validation
- Unique test-data factory
- Local demo application and API
- Chromium, Firefox and WebKit projects
- HTML, JUnit and JSON reporting
- Trace, screenshot and video diagnostics on failure
- GitHub Actions workflow and Docker configuration
- Setup, architecture, environment, authentication, test-data and CI documentation
- Individual commercial-use licence

### Who is it for?

QA automation engineers, SDETs and consultants who already know basic JavaScript/TypeScript and want a maintainable Playwright starting point.

### Requirements

- Node.js 22 or newer
- npm
- Basic JavaScript/TypeScript and web testing knowledge
- Browser binaries installed using the included Playwright command

### Important limitations

TestForge is a source-code starter kit, not a hosted service or a universal drop-in test suite. You must adapt selectors, login flows, API endpoints, schemas, test data and environment settings to your application. It does not include custom integration work, consulting or a guarantee that it will work unchanged with your application.

### Licence

One named individual may use TestForge for personal work, internal business projects and multiple client projects on which they personally work. Client-specific test deliverables may be delivered to clients, but the TestForge starter package and substantial framework source may not be shared or transferred. One licence covers one individual, not a team.

### Updates and support

Includes maintenance releases and bug fixes for the purchased major version for the lifetime of that major version. Future major versions are not included automatically. Product support covers reproducible TestForge defects, not application-specific implementation or consulting.
